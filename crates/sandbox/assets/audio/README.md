Sound effects are original seeded syntheses from `tools/generate-audio.py`.

The military music is an original score in `tools/render-score.py`, rendered using GeneralUser GS v2.0.3 by S. Christian Collins with FluidSynth. The instrument bank is an authoring dependency and is not bundled here; only the completed recordings are shipped. See `GeneralUser-GS-LICENSE.txt` and https://github.com/mrbumpy409/GeneralUser-GS for instrument credits and terms.

`docs/AUDIO.md` describes the arrangements, mixer, event cues, verification and exact rendering-bank checksum.
